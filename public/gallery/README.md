# Gallery Images

Drop your project photos into this folder.

## How to use an image in the gallery

1. Add your image file here, e.g. `my-project.jpg`
2. Open `src/data/projectsData.ts`
3. Set the `imageUrl` for a project to `/gallery/my-project.jpg`

Example:
```ts
imageUrl: '/gallery/my-project.jpg',
```

## Supported formats
JPG, JPEG, PNG, WEBP — all work fine.

## Tips
- Recommended size: 1200 × 800 px or similar landscape ratio
- Keep file sizes reasonable (under 500 KB per image) for fast loading
